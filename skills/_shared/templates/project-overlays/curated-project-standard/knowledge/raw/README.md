# Knowledge Raw — {{PROJECT_NAME}}

Capturas brutas (notas, transcrições, recortes, exports, papers, artigos).

**Nomenclatura obrigatória:** `{YYYY-MM-DD}-{skill}-{topic-kebab}.md`

Exemplo: `2026-04-17-research-hook-patterns.md`

## Subdiretório `assets/`

Imagens, PDFs, exports binários, screenshots — qualquer binário anexado a uma raw source vai em `knowledge/raw/assets/`.

## Compilar raw → wiki

Quando uma captura consolidar um insight durável, compilar para `knowledge/wiki/{sources|entities|concepts|synthesis}/{topic-kebab}.md`. Append entry ao `knowledge/wiki/log.md`.
